# BRIDGES — GitHub Pages site

This directory contains a small static site for the BRIDGES repository.

To publish the site:
1. Go to your repository Settings → Pages.
2. Under "Build and deployment" choose "Branch: main" and folder "/docs".
3. Save. The site will be available at: https://you-mei-code.github.io/BRIDGES

Edit files in the `docs/` folder and push changes to update the site.
